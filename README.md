# SEVENTEEN 포토카드 퀴즈 🎴

포토카드를 보고 **① 어떤 멤버인지 ② 어떤 앨범인지 ③ 발매 연도는 언제인지**를 맞히는
웹 브라우저 퀴즈 게임입니다. 별도 빌드 없이 `index.html`을 열면 바로 실행됩니다.

## 실행

```bash
# 정적 파일이라 아무 정적 서버로도 실행 가능
python3 -m http.server 8000
# → http://localhost:8000
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.

## 게임 규칙

- 카드 1장당 3문제(멤버 / 앨범 / 발매연도), 각 4지선다
- 한 판 = 8장, 문제당 10점 (만점 240점)
- 정답률에 따라 캐럿 등급 부여 (관심 → 입덕 준비생 → 진성 캐럿 → 캐럿 마스터)

## 구조

```
index.html      # 화면 구조 (시작 / 플레이 / 결과 3개 섹션)
css/style.css   # 다크 테마 · 반응형 스타일
js/data.js      # 정답 소스: MEMBERS / ALBUMS / CARDS 데이터
js/game.js      # 게임 엔진: 라운드 진행 · 보기 생성 · 채점 · 결과
assets/cards/   # (선택) 실제 포토카드 이미지 배치 위치
```

정답 데이터는 전부 `js/data.js` 한 곳에서 관리합니다. 실제 포토카드 이미지를
`assets/cards/`에 넣고 `CARDS[].image`에 경로를 지정하면, 플레이스홀더 대신
실제 이미지가 표시됩니다.

## 현재 상태 (데모)

- ✅ 게임 루프 · 채점 · 결과 · 재시작 정상 동작 (Playwright E2E 검증 완료)
- ⚠️ 실제 포토카드 이미지 미포함 → 현재는 SVG 플레이스홀더로 대체
  (저작권 문제로 정품 스캔 이미지는 포함하지 않음)

자세한 개선 과제는 [`ANALYSIS.md`](./ANALYSIS.md) 참고.
