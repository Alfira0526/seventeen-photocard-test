# SEVENTEEN 앨범 자켓 퀴즈 🎴

앨범 자켓(커버)을 보고 **① 어떤 앨범인지 ② 발매 연도는 언제인지 ③ 타이틀곡은 무엇인지**를
맞히는 웹 브라우저 퀴즈 게임입니다. 별도 빌드 없이 `index.html`을 열면 실행됩니다.

> 처음엔 "포토카드로 멤버 맞히기"였으나, 저작권 안전 + 이미지 확보 용이성을 위해
> **공개 앨범 자켓 기반**으로 전환했습니다. 자켓엔 특정 멤버가 없어 문제도
> 멤버 → **타이틀곡**으로 교체했습니다. (배경은 [`ANALYSIS.md`](./ANALYSIS.md))

## 실행

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## 앨범 자켓 이미지 채우기 (한 번만)

이미지 파일은 저작권상 리포에 담지 않습니다. 대신 **iTunes(Apple) 아트워크 CDN URL**을
`js/albumArt.js`에 베이크해 두고 런타임에 `<img>`로 불러옵니다.

```bash
node scripts/fetch-art.mjs
```

- iTunes Search API를 호출해 앨범별 자켓 URL(600×600)을 찾아 `js/albumArt.js`를 생성합니다.
- **인증 불필요**, 이미지 바이너리는 저장하지 않고 URL만 저장 → 리포가 깨끗합니다.
- 이 스크립트를 돌리기 전에는 각 앨범이 SVG 플레이스홀더("NO IMAGE")로 표시됩니다.
- 매칭 실패한 앨범은 콘솔에 경고로 남고 해당 앨범만 플레이스홀더로 유지됩니다.

> 왜 파일을 안 담나요? 자켓도 저작권물이라 **재배포**가 문제입니다. 공식 CDN에서
> 식별 목적으로 로드하면 리포에 저작물을 담지 않게 되고, 출처/화질도 안정적입니다.

## 게임 규칙

- 자켓 1장당 3문제(앨범 / 발매연도 / 타이틀곡), 각 4지선다
- 한 판 = 8장, 문제당 10점 (만점 240점)
- 정답률에 따라 캐럿 등급 (관심 → 입덕 준비생 → 진성 캐럿 → 캐럿 마스터)

## 구조

```
index.html            # 화면 구조 (시작 / 플레이 / 결과)
css/style.css         # 다크 테마 · 반응형
js/logic.js           # 순수 로직(셔플·보기 생성·등급) — 브라우저/Node 공용, 테스트 대상
js/data.js            # 정답 소스: ALBUMS(제목·연도·유형·타이틀곡) + 무결성 검증
js/game.js            # 게임 엔진: 라운드 진행 · 채점 · 결과 (DOM 전담)
js/albumArt.js        # (자동 생성) 앨범 자켓 CDN URL — scripts/fetch-art.mjs 산출물
scripts/fetch-art.mjs # iTunes 아트워크 수집기
tests/quiz.test.mjs   # 순수 로직 + 데이터 무결성 단위 테스트
```

## 테스트

```bash
node --test          # 순수 로직 + 데이터 무결성 (9 tests)
```

브라우저 E2E는 Playwright로 시작→8라운드→채점→결과→재시작 흐름을 검증합니다.

## 현재 상태

- ✅ 게임 루프 · 채점 · 결과 · 재시작 정상 (Node 단위테스트 9/9, Playwright E2E 통과)
- ✅ 로직/데이터/DOM 분리, 데이터 로드시 무결성 검증
- ✅ 앨범/연도/타이틀곡 데이터 **웹서치 3라운드 교차검증 완료** (앨범 20개, ANALYSIS.md 로그)
- ⚠️ `js/albumArt.js` 생성 전에는 플레이스홀더 표시 → `node scripts/fetch-art.mjs` 1회 실행 필요

남은 개선 과제는 [`ANALYSIS.md`](./ANALYSIS.md) 참고.

## 면책

팬메이드 비영리 데모입니다. 앨범 자켓 등 이미지의 저작권은 각 저작권자(플레디스 등)에게
있으며, 식별 목적으로 Apple Music CDN에서 로드합니다.
