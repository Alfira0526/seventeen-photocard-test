# 시즌 & 랭킹 데이터 저장 구조

이 문서는 랭킹 시즌이 **언제 바뀌는지**와, 지난 시즌 데이터가 **어디에 어떻게 보관되는지**를 설명합니다.
관련 코드: `js/season.js`(스케줄), `js/ranking.js`(저장/조회).

---

## 1. 시즌 주기

- **월간 시즌**: 매월 1일 시작 → 말일 종료. 매달 리셋되고 매달 챔피언이 나옵니다.
- **분기 누적**: 별도 리셋이 아니라, 그 분기(3개월)의 월간 데이터를 **합산한 뷰**입니다.
- **오픈베타**: 월간 도입 이전의 구 기록(접미사 없음).

## 2. 종료 시각 — 한국시간(KST) 기준

시즌 경계는 `season.js`에서 **한국시간(KST, UTC+9)** 기준으로 계산됩니다.
내부 계산은 UTC epoch(ms)에 +9h를 더해 한국 벽시계로 환산한 뒤, 경계 순간을 다시 UTC로 되돌립니다.

```js
var KST = 9 * 3600000;                 // 한국시간 오프셋
start: Date.UTC(y, m - 1, 1) - KST     // 그 달 1일 00:00 KST
end:   Date.UTC(y, m, 1)     - KST     // 다음 달 1일 00:00 KST
```

| 시즌 | 시작(KST) | 종료(KST) |
|------|-----------|-----------|
| 7월 | 7/1 00:00:00 | **7/31 23:59:59** (=8/1 00:00 직전) |
| 8월 | 8/1 00:00:00 | 8/31 23:59:59 |

즉 **7월은 한국시간 7/31 자정에 마감**되고, 8/1 00:00 KST부터 8월 시즌이 시작됩니다.

### 종료 공지 & 카운트다운

| 구간 | 노출 |
|------|------|
| 종료 **2일 전(D-2)** 부터 | 배너 '막판 순위 굳히기' 강조 (`isFinalPush()`) |
| 종료 **2시간 전** 부터 | 실시간 카운트다운 `H:MM:SS` (`isFinalCountdown()`, 1초 갱신) |

설정값은 `season.js`의 `CFG = { noticeDays: 2, countdownMs: 2h }`에서 조정합니다.

## 3. 데이터 저장 위치 — 삭제 없이 월별로 영구 보관

데이터는 **append-only**(추가만, 삭제·덮어쓰기 없음)입니다. "리셋"은 데이터를 지우는 게 아니라 **저장 키가 달라지는 것**을 뜻합니다.

### 원격(Firebase Realtime Database)

경로 형식: `rankings/<모드><접미사>`

| 시즌 | 접미사 | 저장 경로 예시 |
|------|--------|------|
| 오픈베타 | 없음 (`""`) | `rankings/normal` |
| 2026-07 | `_202607` | `rankings/normal_202607`, `rankings/timeattack_202607` |
| 2026-08 | `_202608` | `rankings/normal_202608` |

- 접미사는 `season.js`의 `active().suffix`가 제공합니다(예: `_202608`).
- 8월이 시작되면 새 점수는 `_202608` 키로 저장되고, **7월 데이터(`_202607`)는 그 자리에 그대로 남습니다.** 언제든 다시 조회 가능합니다.
- 테스트베드(`/preview/`)는 데이터 격리를 위해 경로 앞에 `staging/`이 붙습니다: `staging/rankings/normal_202608`.

### 로컬(localStorage)

- 키: `svt-ranking` (테스트베드는 `svt-ranking-staging`).
- 모든 시즌 기록이 한 배열에 섞여 저장되고(최대 300건), **조회 시 월 접미사로 걸러냅니다.**
- 기기별 저장이라 그 브라우저에서만 보입니다. 교차기기 공유는 원격(Firebase)이 담당합니다.

## 4. 조회 방식

`ranking.js`의 `list(mode, opts)`:

- `opts` 없음 → **현재 달** (`active().suffix`)
- `{ suffix: "_202607" }` → **특정 달** (예: 지난 달)
- `{ suffixes: [...] }` → **여러 달 병합** (분기 누적 뷰; `quarterMonths()`가 접미사 목록 제공)

정렬: 점수 내림차순, 동점이면 먼저 기록된 순(ts 오름차순). 중복은 `모드|이름|점수|ts`로 제거.

## 5. 요약

- 지난 시즌 순위는 **사라지지 않습니다.** 월 접미사가 붙은 별도 키에 그대로 남습니다.
- 새 시즌은 그저 **새 키에 기록을 쌓기 시작**할 뿐입니다.
- 분기 순위는 저장이 아니라 **여러 달을 합친 계산 결과**입니다.
